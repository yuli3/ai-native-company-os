# 사장님을 위한 AI-native 운영 OS: 30분 설치 가이드

이 가이드는 복잡한 코딩 없이, 사장님의 컴퓨터를 똑똑한 AI 직원들이 일하는 '운영 본부'로 만드는 과정입니다. 이제 마우스 클릭과 간단한 명령어 복사로 AI 비서를 고용하세요.

---

### (a) 사전 준비
1. 컴퓨터에 **Docker Desktop**(도커 데스크톱)을 설치하세요. (구글에 'Docker Desktop 다운로드' 검색 후 설치)
2. 설치 후 프로그램을 실행해두기만 하면 됩니다.

### (b) Hermes 런타임 설치
컴퓨터에 AI가 살 수 있는 '사무실'을 짓는 과정입니다.

**명령어:**
docker run -d -p 8080:8080 --name hermes-os <회사명>/hermes-runtime:latest

**이렇게 보이면 성공:**
터미널(검은 창)에 긴 영문과 숫자가 섞인 코드가 출력되고, 잠시 후 아무런 에러 메시지가 뜨지 않으면 설치 완료입니다.

### (c) 관제 대시보드 실행
사장님이 AI 직원들에게 지시를 내릴 '관리자 화면'을 엽니다.

**명령어:**
docker start hermes-os

**이렇게 보이면 성공:**
인터넷 브라우저(크롬 등)를 열고 주소창에 `http://localhost:8080`을 입력하세요. "Hermes 운영 OS에 오신 것을 환영합니다"라는 화면이 뜨면 성공입니다.

### (d) 모델 연결 (AI 두뇌 장착)
AI가 생각할 수 있도록 두뇌를 연결합니다. 무료 모델을 우선 추천합니다.

1. **무료 모델 (Gemini):** [Google AI Studio](https://aistudio.google.com/) 접속 -> 'Get API key' 클릭 -> 발급받은 키를 복사.
2. **로컬 모델 (Gemma):** 인터넷 연결 없이 보안이 중요한 업무를 할 때 사용합니다. (대시보드 설정 메뉴에서 'Gemma' 선택)
3. **유료 모델:** 더 정교한 업무가 필요할 때 대시보드 내 '결제 설정'에서 API 키를 입력하세요.

**대시보드 입력 방식:**
대시보드 설정 메뉴 -> [AI 엔진 연결] -> 'YOUR_API_KEY' 칸에 복사한 키를 붙여넣고 [저장] 버튼 클릭.

**이렇게 보이면 성공:**
설정 화면 하단에 "연결 상태: 활성(Active)"이라는 초록색 불이 들어옵니다.

### (e) 첫 실행 확인
이제 AI 직원에게 첫 업무를 시켜보세요.

**채팅창에 입력:**
"오늘 매출 데이터를 분석해서 가장 많이 팔린 메뉴 3가지를 정리해줘."

**이렇게 보이면 성공:**
잠시 후 화면에 AI 직원이 분석한 결과가 표나 리스트 형태로 깔끔하게 정리되어 나타납니다.
