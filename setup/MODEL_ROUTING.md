모든 업무에 비싼 유료 모델을 쓸 필요가 없습니다. 단순한 일은 무료 모델이, 복잡한 기획이나 분석은 유료 모델이 맡아 비용을 아낍니다.

### 2. 상황별 모델 선택 전략

* **일상적인 소통과 요약 (Gemini Flash-Lite):** 
  거래처 메일 초안 작성, 오늘 들어온 고객 문의 요약 등 반복적인 업무는 무료 모델로 충분합니다. 속도가 빨라 사장님의 시간을 뺏지 않습니다.
* **중요한 전략 수립 (유료 모델):** 
  신메뉴 개발 아이디어, 마케팅 전략 수립, 복잡한 엑셀 데이터 분석 등 '머리 쓰는 일'은 유료 모델을 호출합니다. 정확도가 높아 실수를 줄여줍니다.
* **보안이 걱정될 때 (로컬 Gemma):** 
  가게의 매출 장부나 개인정보가 포함된 문서를 다룰 때는 인터넷 연결이 필요 없는 '로컬 모델(Gemma)'을 사용하세요. 외부로 정보가 나갈 걱정이 전혀 없습니다.
