Add one line per lesson, with the date and the rule it produced. Examples from a real agent-run company:

- 2026-11-21 The build machine's disk filled up and every agent stopped. **Rule:** delete your own build caches and merged worktrees when you finish.
- 2026-11-22 A secret sat in an archived planning file in git history for weeks. **Rule:** scan for secrets before archiving; rotate anything found.
- 2026-11-20 The founder was asked to paste terminal commands from a phone. **Rule:** agents run commands; if the founder must, give one double-click script.
- 2026-11-13 A contest entry was fully built but never submitted, because submission needed the founder's video and name. **Rule:** list founder-only steps on day one, not on the deadline.
- 2026-11-03 A batch of ten questions sat unanswered for a day. **Rule:** at most five, each with a recommendation and default; proceed on the default if reversible.
