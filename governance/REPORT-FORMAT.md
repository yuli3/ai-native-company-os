# 보고·인계 형식

에이전트가 오너나 다른 에이전트에게 남기는 보고의 표준 형식입니다. `harness/check-report.mjs`가 이 형식을 검사합니다.

본문은 한 화면(대략 3,000자) 안에 둡니다. 근거 자료, 로그, 표 원본은 링크나 부록으로 뺍니다.

```markdown
# (작업 이름)

## 목표 대비 진척
원래 목표: (한 줄)
이번 진척: (한 줄. 없으면 "없음"과 이유)

## 결정 요청
1. 질문: …
   선택지: A / B
   추천: A, 이유 한 줄
   기본값: 답이 없으면 A로 진행

## 한 것
- (산출물 링크: PR, 커밋, 파일 경로)와 한 줄 설명
- 검증: 실행한 명령과 결과

## 안 한 것
- (항목) — 이유, 해제 조건, 담당

## 확인하지 못한 것
- (항목) — 왜 못 했는지

## 다음 행동
- (누가) (무엇을)
```

결정 요청이 없으면 그 절은 "없음"이라고 씁니다. 지우지 않습니다.
