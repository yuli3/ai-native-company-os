# AI-Native Company OS — SMB Starter

소상공인·중소기업이 **자기 회사용 AI 운영 OS**를 30분 안에 세팅하는 스타터 패키지입니다.
사장님은 **보고를 받고, 명령은 자연어(채팅)로** 내립니다. AI 직원(종합·전문 에이전트)이 실제 작업을 실행합니다.

> 개인정보·자격증명·특정 회사 고유 데이터는 포함하지 않습니다(제네릭 템플릿). 설치 시 본인 회사 정보로 채웁니다.

## 무엇인가
- **자연어로 운영하는 회사** — 채팅으로 목표를 주면 AI가 작업으로 분해·실행·검증.
- **사람은 감독자** — 대시보드로 "지금 무슨 일이 벌어지고, 내 결정이 필요한 건 뭔지"만 확인.
- **무료 우선 모델 라우팅** — 대량 작업은 무료/로컬 모델(예: 경량 클라우드·로컬 LLM), 고난도만 유료 모델.
- **자율 사다리(1→2→3)** — ① 닫힌 작업 루프(검증 게이트 통과만 완료) ② 트렌드 정찰 → 아이디어 ③ 자기개선 제안.

## 빠른 시작
1. `setup/INSTALL.md` — 런타임 + 관제 대시보드 + 모델 연결(가장 간단한 경로).
2. `templates/env.example` 를 복사해 본인 키·회사 정보 입력.
3. `templates/agent-roster.md` 로 AI 직원(역할) 구성, `templates/goals.example.json` 로 목표 보드 시작.
4. `manuals/` 에서 본인 업종 매뉴얼 선택(요식업·소매업·서비스업 템플릿).
5. `playbooks/autonomy-playbook.md` 로 자율 단계 점진 활성화.
6. 에이전트를 여럿 쓴다면 `governance/README.md` 로 공통 헌법과 보고서 검사를 붙입니다.

## 구성
| 폴더 | 내용 |
|---|---|
| `setup/` | 설치 가이드 · 모델 라우팅 설정 |
| `manuals/` | 업종별 운영 매뉴얼 템플릿 |
| `templates/` | 에이전트 역할 · 목표 보드 · `.env` 예시 |
| `playbooks/` | 자율 운영 플레이북(자율 1/2/3단계) |
| `checklists/` | 도입 · 운영 · 보안 체크리스트 |
| `governance/` | 에이전트 헌법 · 자율 등급 · 행동 교정 카탈로그 · 보고서 검사 도구 |

## 안전 기본값
- 배포·결제·민감 작업은 **사람 승인 게이트** 유지(자율 모드에서도).
- 검증 게이트(type-check·build 등) 통과한 작업만 "완료"로 인정.
- 자격증명은 `.env`에만, 저장소에 커밋 금지.

## 라이선스 · 면책
- 제공 형태(라이선스·가격)는 배포처에서 정의합니다(이 스타터엔 미포함).
- 이 OS는 운영 보조 도구입니다. 법률·세무·의료·투자 등 전문 판단은 자격 전문가의 확인을 거치세요.
